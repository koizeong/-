# デスクトップ版(Windows)

旅団戦術シミュレーションを、ダブルクリックで起動するソフトにする(Electron)。アプリの中でゲームサーバーを動かし、専用の窓で画面を開く。
編成エディターは入れていない(開発用の起動 `pnpm dev` でだけ使う)。

## 作り方

リポジトリの上で一度 `pnpm install` を済ませてから:

```
cd desktop
npm install
npm run dist:win              # dist/brigade-sim-<版>-win-x64.zip(展開してすぐ遊べる)
npm run dist:win-installer    # インストーラー(.exe)。Windows の上で実行する(Linux では Wine が要る)
```

`npm start` で、作った中身をその場で起動して確かめられる。

## 中身

- `build.mjs`:画面をビルドし(`pnpm build`)、ゲームサーバーを esbuild で1つのファイル(`app/server.mjs`)にまとめ、`data/` を写す
- `main.mjs`:空いているポート(47321 から順に)でゲームサーバーを立て、専用の窓で開く。2つ目を起動したら、開いている窓を前に出す
- セーブ・キャンペーンの保存はアプリの中のブラウザの保存場所に残る。ポートごとに分かれるので、毎回同じポート(47321)を使う

## 友人に配るとき

- zip を展開し、中の「旅団戦術シミュレーション.exe」を起動する
- 署名していないので、初回に「Windows によって PC が保護されました」と出たら「詳細情報 → 実行」
## オンライン対戦(デスクトップ版どうし)

1. 部屋の主:表紙 → オンライン対戦 → 「対戦を受け付ける」を入れる。出たアドレスを相手に伝える
   (同じ Wi-Fi なら 192.168.… など、離れていれば Tailscale の 100.… )。初回に Windows のファイアウォールの確認が出たら「アクセスを許可する」
2. 部屋の主:「部屋を作る」で部屋を作り、合言葉も伝える
3. 入る側:オンライン対戦 → 「ほかの PC の部屋に入る」にアドレスを入れて「つなぐ」 → 合言葉で「合言葉で入る」
4. 終わったら「自分の PC に戻る」

- 受け付けている間は、番号 47320 のすべてのアドレスで受け、自分のゲームサーバー(127.0.0.1:47321)へそのまま中継する
- 離れた友人とは、両方の PC に Tailscale(無料の仲間内 VPN)を入れて同じネットワークに参加する。インターネットに口を開ける必要はない
