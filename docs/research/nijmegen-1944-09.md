## 2. 地形

- **フルースベークの高地**:「ナイメーヘンの南東約6マイルにある、森に覆われた長い稜線。三角形の台地で、まわりより約300フィート(約90m)高い」(WHN https://warfarehistorynetwork.com/article/u-s-82nd-airborne-division-mook-holland-operation-market-garde/ )。ただし「300フィート高い」は比高ではなく標高と取り違えている可能性がある。地点ごとの標高は次のとおり。ドゥイフェルスベルフ 75.9m(https://en.wikipedia.org/wiki/Duivelsberg 。ナイメーヘン東の氷河の堆積丘)。フルースベークの最高点 約90m(弱い出典 https://www.tau.ac.il/~tsirel/dump/Static/knowino.org/wiki/Groesbeek.html )。フルースベークの村 34m。→ 高地の頂は標高およそ75〜90m、まわりの低地(ワール・マースの氾濫原)は約10m前後と推定。**低地の標高は TODO(要裏取り)**(AHN の標高図で確かめる)。高地は「何マイルも続く中で唯一の高地」で、橋と平地を見下ろしていた(Gavin の1945年の書簡を引く https://v3.tracesofwar.com/articles/item.php?id=4760 、https://warhistory.org/article/from-neptune-to-market-ii )。確度:中
- **ライヒスヴァルトの森**:51km²(5,100ha)。ドイツ国境の内側(https://en.wikipedia.org/wiki/Klever_Reichswald 、https://www.ich-geh-wandern.de/reichswaldroute )。高地の東約3マイル。確度:高(面積)
- **Sint Jansberg**:モーク〜プラスモーレンの氷河堆積丘で、自然保護団体 Natuurmonumenten の森(約250ha)(https://en.wikipedia.org/wiki/Mook_en_Middelaar 、https://www.komoot.com/highlight/422984 )。9月18日に Sint Jansberg の近くにグライダーが墜落し、LZ N を守っていた中隊長が戦死した(https://www.europeremembers.com/pois/450/freedom-falls-from-the-skies )。森の範囲・標高は TODO(要裏取り)
- **ナイメーヘンの市街**:1944年当時の市街の範囲は TODO(要裏取り)。戦闘地点はケイゼル・カレル広場(Keizer Karelplein)、ケイゼル・ローデウェイク広場(橋の南のたもと)、フンネル公園、ファルクホフ、郵便局(起爆装置があると考えられて攻撃目標になった)(https://www.liberationroute.com/en/pois/1090/the-crossing-of-the-river-waal )
- **ワール川**:平均の川幅は350〜400mで、レントの向かいがいちばん狭い(TU Delft https://ocw.tudelft.nl/course-lectures/2-2-case-study-the-waal-river/ )。1944年の渡河地点での川幅(よく言われる「約400ヤード」)は検索で確かめられなかった → TODO(要裏取り)。鉄道橋の全長は675m(氾濫原を含む)
- **マース川(グラーヴェ)**:川幅は見つからない → TODO(要裏取り)。グラーヴェ橋の構造と全長(約250m?)も未確認
- **マース=ワール運河**:長さ13.5km(Wikipedia)、Rijkswaterstaat では13km。南端はヘウメンの閘門でマース川に、北端はナイメーヘン西のウェールトの閘門でワール川につながる。1927年10月27日に開通(https://en.wikipedia.org/wiki/Maas%E2%80%93Waal_Canal 、https://www.rijkswaterstaat.nl/water/vaarwegenoverzicht/maas-waalkanaal )。確度:高

### 9月19日(火)
- 08:20 近衛騎兵の装甲車がグラーヴェ橋に到着(08:30とする出典もある)、10:00ごろ近衛擲弾兵の戦車。ヘウメンの閘門橋を通ってナイメーヘンへ

### 9月20日(水)

### ナイメーヘン道路橋が爆破されなかった理由
- Harmel は「連合軍に奪われそうなら爆破する」許可を Model に求めたが、Model は拒んで死守を命じた(反撃に使うため)。戦後、退役将官5人の委員会は「道路橋が残ったのは Model の決定による」と結論した。オランダのレジスタンス Jan van Hoof が導線を切ったという説は議論が分かれる(のちに蘭・米が叙勲)。一部の爆薬が不良だったという説もある(https://www.battledetective.com/battlestudy16.html 、https://www.excitinghistory.com/location/nijmegen-eenmaal-in-je-leven-iets-goed-doen-jan-van-hoof/ 、https://www.tracesofwar.com/sights/38957/Liberation-Route-Marker-14.htm )。20日夕方に Harmel が起爆を命じたが爆発しなかったとする話(Ryan など)は今回の検索では確かめていない → TODO。確度:中
