# チピョンニ(砥平里)の戦い 1951年2月13〜15日(シナリオ chipyong-ni-1951-02-13 の根拠)

`tools/scenarios/build_chipyong_ni_1951_02_13.py` が `data/scenarios/chipyong-ni-1951-02-13.json` を作る。v0・概略図。
部隊は国ごとの実数の編成表(定数。`equipment-us.md`・`equipment-korea.md`)をそのまま使う。調べ方:WebSearch の要約だけ。

## 1. 地図

- 村の中心:37.475, 127.637(中:[Wikipedia『Jipyeong-ri』](https://en.wikipedia.org/wiki/Jipyeong-ri)。砥平駅は 37.4765, 127.6297)。
- 周りの高地(248・345・397高地など)・ツイントンネル・道路の形は座標が確かめられず入れていない(TODO(要裏取り):Gugeler『Combat Actions in Korea』の地図)。
- 目標は村の中心の半径500m。範囲の中の部隊の数で持ち主が決まるので、全周の陣地(半径800m の**仮置き**)を抜けないと取れない。

## 3. 時間・勝利条件・結末

- 13日17:00〜15日18:00 の49ターン。夜(18:00〜07:00)は暗い時間として1時間ごとに解く。日の出・日の入りは TODO。
- 志願軍:村を取れば決定的、国連軍に3割の損害で限定的。国連軍:村を保てば限定的、さらに志願軍に3割の損害で決定的(ゲームの設計)。
- 史実:国連軍が村を守り抜き、15日の夕方にクロンベズ任務部隊がつながった。志願軍の損害は米の見積もりで戦死約2,000・負傷約3,000(Wikipedia)。

## 4. AI 同士の対戦(6戦)

| 配置 | 結果 |
|---|---|
| 志願軍の連隊12(6+6)、目標の半径1000m | 志願軍の決定的勝利 6/6。範囲が陣地の環まで含み、部隊の数で取られた |
| 目標の半径を500m に | 志願軍5・国連軍1 |
| 志願軍の連隊を8(4+4)に | 志願軍3・国連軍3 |

**残る問題**:夜の撃ち合いで志願軍の連隊の損害が小さい(1戦で数%〜1割)。史実の大損害は出ない。暗い時間の見通しで、陣地からの射撃が届きにくいためとみられる(TODO:`validation.md` でエドソンの丘と合わせて確かめる)。
