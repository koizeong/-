# 中国国民革命軍(国民政府軍)の装備品と実数の編成(パック roc の根拠)

`tools/packs/build_roc.py` が `data/weapons/roc.json`・`data/toe/roc.json` を作る。1944年(大陸打通作戦)。ID は `roc-`(朝鮮戦争の中国人民志願軍の `cn-` と分ける)。
調べ方:この環境では資料を確かめられず、一般に知られた装備の名前だけを使った。**数・人員・弾の重さ・射程はほぼすべて仮置き**。
1944年の国民政府軍の師団は定数に大きく届かず、装備も足りなかったとされる(キャンペーンでは戦力0.6で置く)。
