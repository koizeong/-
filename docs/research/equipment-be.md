# ベルギー軍の装備品と実数の編成(パック be の根拠)

`tools/packs/build_be.py` が `data/weapons/be.json`・`data/toe/be.json` を作る。1940年(黄作戦)。
調べ方:この環境では資料を確かめられず、一般に知られた装備の名前だけを使った。**数・人員・弾の重さ・射程・貫通力はほぼすべて仮置き**。
