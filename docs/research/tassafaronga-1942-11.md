# タサファロンガ沖海戦(ルンガ沖夜戦)1942年11月30日 — シナリオ v0 の根拠

海戦の作り直し S8 の2つ目の戦い。サボ島沖海戦の逆で、電探で先に見つけた米艦隊が、九三式魚雷の雷撃に負けた。
シナリオは `data/scenarios/tassafaronga-1942-11-30.json`、作り直しは `tools/scenarios/build_tassafaronga_1942_11_30.py`。

## 経過(要約)

- 田中頼三少将の第二水雷戦隊(駆逐艦8。うち6隻はガダルカナル島の守備隊へのドラム缶の補給を積み、次発装填の魚雷を降ろしていた)が、エスペランス岬を回って岸沿いに南東へ下る。高波は警戒艦
- ライト少将の第67任務部隊(重巡ミネアポリス・ニューオーリンズ・ペンサコラ・ノーザンプトン、軽巡ホノルル、駆逐艦6)は東から。23:06 にミネアポリスの SG 電探が約 23,000ヤードで日本の駆逐艦を捉えた
- 前衛の駆逐艦は雷撃の許可を待つ間(2〜4分)に射点を失い、23:20 ごろ遠い追いかける形で撃った魚雷(約20本)は全部外れた
- 巡洋艦の砲火(23:21〜)は、いちばん近い高波に集まって沈めた。その閃光を目印に、日本の駆逐艦は九三式魚雷(約40本)を放ち、23:27 ごろからミネアポリス・ニューオーリンズ・ペンサコラ・ノーザンプトンに当たった
- ノーザンプトンが沈み、ほかの3隻は大破。日本は高波を失い、補給物資は落とせずに引き揚げた

## 確かめて直したこと(S8)

最初の版では、AI 同士6戦で日本の駆逐艦がほぼ全滅し、米の損耗は1割前後(史実と逆)だった。原因と直し:

1. 夜の砲戦が昼と同じように当たった(発砲の光で見えた目標には、昼の命中の表がそのまま効いた)→ 夜の砲戦の命中の倍率 `naval.gunnery.nightHitMultiplier` 0.5(仮置き)
2. 日本の駆逐艦が敵に艦首を向けたまま追い、発射管(舷側)が向かなかった。戦いは20分のターンの中で決まるので、ターンの始めの AI の判断は間に合わない
   → 夜の駆逐艦の戦隊は「魚雷の届く距離に敵を見つけたら雷撃して反転」の条件付き命令を始めから持つ。雷撃して反転の艦は、届く距離で発射管が向かなければ舷側を向ける向きへ舵を切る
3. 魚雷を射程の7割から撃ち、九三式は 14km から撃って当たりにくかった → 撃つ距離を射程の半分に(`naval.torpedoes.launchRangeShare`・`turnAwayLaunchShare` 0.5。夜戦の雷撃はたいてい射程よりずっと近くから撃った)
4. 退避・雷撃の行き先が陸の上になり、艦が乗り上げた → 艦は陸へ進まない。行き先は海の上へ左右に振って探す(`seaPoint`)
5. 撃った艦が沈んだ後の魚雷の当たりで止まった → 直した

## 結果(AI 同士、直した後)

6戦で日本の決定的勝利2・引き分け4(米の勝ちはない)。米の損耗 0.15〜0.47、日本 0.21〜0.54。

- 合っているところ:米が先に見つけて先に撃つが、日本の雷撃で米も大きく傷つく。米の勝ちにはならない
- 合っていないところ:日本の損耗が史実(高波1隻)より大きく、米の艦は沈まない(史実はノーザンプトンが沈んだ)。引き分けが多い。
  原因の候補:日本の駆逐艦が雷撃の後も撃ち合いに残る、高波だけに砲火が集まらない(いちばん近い艦を撃つ決まりがない)、九三式の当たりの割合(`aimChance`)
