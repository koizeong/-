# 調査メモ:ヴェーザー演習作戦(ノルウェーの戦い。1940年4月9日〜6月10日)のキャンペーン

対象:キャンペーン(作戦の層)。地域を点、道路・鉄道を線でつないだ概略図、1段階4日・16段階。
部隊は独軍が連隊、連合軍(ノルウェー・英・仏・ポーランド)が大隊(仏・ポーランドの半旅団・旅団は連隊1つ)。

## 0. キャンペーンに効く要点

- 4月9日に独軍はオスロ・クリスチャンサン・スタヴァンゲル(ソラ飛行場は降下猟兵)・ベルゲン・トロンハイム・ナルヴィクを同時に押さえた。
  オスロではブリュッヒャーがドレーバク海峡でオスカシュボル要塞に沈められ、オスロは空から降りた部隊で取った。→ v0 では6つの港を始めから独の地域にした(上陸の戦闘は表さない)
- ノルウェー軍は動員所を押さえられて動員が乱れ、内陸の谷(グドブランスダール・エステルダール)とヴォス・トロンデラーグ・北ノルウェーで戦った。
  → 大隊の戦力を0.6〜0.8、第6師団(北)だけ標準の練度で満たした
- 英仏ポーランドの連合軍は、中部ではナムソス(モーリス部隊)とオンダルスネス(シックル部隊)に上がってトロンハイムを挟もうとしたが、5月2〜3日に引き揚げた。
  北ではハーシュタを根拠地にナルヴィクを攻め、5月28日に取り返したが、6月8日までに引き揚げた
- 独の補給:オスロ・クリスチャンサンはスカゲラク(海)、スタヴァンゲル・トロンハイムは空輸(v0 では海を通らない補給の源)。ナルヴィクは補給の源なし(孤立)
- 連合軍の補給:オークニー(スカパ・フロー)、ハーシュタ(ヴェストフィヨルド)、オンダルスネス・ナムソス(ノルウェー海)。ノルウェー軍の内陸の補給の源はハーマル・ヴォス(ゲームの見立て)

## 1. 地域と結び(概略)

緯度経度からのおおよその km(経度1度は北緯63度の値)。オスロからナルヴィクまで約1,000km。
主な鉄道:ドヴレ線(オスロ〜ハーマル〜リレハンメル〜ドンボース〜トロンハイム)とラウマ線(ドンボース〜オンダルスネス)、
ローロス線(ハーマル〜エルヴェルム〜レーナ〜ローロス〜トロンハイム)、ベルゲン線(ヘーネフォス〜ヴォス〜ベルゲン)、
北ノルウェーは鉄道がなく、トロンハイムの北はシュタインシェール・ナムソスまで。ナルヴィクのオフォーテン線はスウェーデンへ。
トロンハイムからナルヴィクへは道がほとんどなく、グロング・モショーエン・モー・ボードー(フォウスケ)と地域を細かく分けて小道でつないだ(1段階に1つしか進めないので、北上にかかる日数を地域の数で表す)。TODO(要裏取り):1940年の道路の状態。

雪の多い山と森は「冬のアルデンヌ」の地形の傾向で代え、オスロ・エストフォル・クリスチャンサン・スタヴァンゲル・トロンハイムは西欧の農村とした(仮置き)。

## 3. 勝利の条件(ゲームの決め方)

- 独:ナルヴィク4・トロンハイム4・オスロ3・ベルゲン2・ハーシュタ2・ハーマル・オンダルスネス・ナムソス各1・損耗比2。決定的=14点でナルヴィクとトロンハイム、限定的=9点でトロンハイム
- 連合:ナルヴィク4・トロンハイム4・ハーシュタ2・ベルゲン2・ハーマル1・損耗比2。決定的=10点でナルヴィクとトロンハイム、限定的=6点でハーシュタ
- 史実の結末は独の決定的勝利

## 4. AI 同士の結果(v0)

- 種1〜4:独の決定的勝利4(史実と同じ)。連合軍の損耗は7〜9割。南ではノルウェー軍が2〜5段階目に崩れ、オンダルスネス・ナムソスは4〜9段階目に落ちる。
  北では連合軍がナルヴィクを取り返す種もある(種3は9段階目=5月中旬。史実は5月28日)が、独が北上してボードーに12段階目(5月下旬)ごろ着き、最後はハーシュタまで取る種が多い
- 1段階目にヴェストフィヨルド(第一次ナルヴィク海戦)とノルウェー海(レナウン対シャルンホルスト・グナイゼナウ)で海戦になり、どちらも独が勝つことが多い
- 直したこと(どれもデータだけ):
  - 英の本国艦隊が1段階目にスカゲラクを取り、オスロの補給と増援を最後まで止めてしまった → オスロへはカテガット(地図の外。機雷原と独空軍に守られた)を通るとして、海に左右されないようにした
  - ナルヴィクの駆逐艦がヴェストフィヨルドに居座り、ハーシュタの補給と増援(近衛旅団・仏・ポーランド)が着かなかった → ハーシュタは北のアンドフィヨルドの海域に面するように分けた(連合軍の船団は外洋から来た)
  - 独がトロンハイムから3段階でボードーへ着いた(史実は約7週間)→ グロング・モー・フォウスケを足して、北上の道を細かく分けた
- 残る違和感:連合軍が南の谷で持ちこたえられない(ノルウェー軍の大隊が弱く、英の旅団は野砲を持たない)。独空軍が連合軍の上陸を苦しめたことは、航空隊の任務の結果次第
