# 史実の海戦から見た、海戦の決まりに要るもの・要らないもの

S1〜S7 で作った海戦(1隻=1ユニット・砲戦・走る魚雷・落伍・艦ごとの航空攻撃・AI・キャンペーンの港)を、史実の海戦の中身と突き合わせた。
S8(史実の戦いで確かめる)の前に、何を足し、何を外すかを決めるための下調べ。**数値の多くは二次資料の要約で、裏取りはまだ**(各項の TODO(要裏取り) と出典候補を見る)。

## 2. 史実の海戦を決めていた要素(重い順)

1. **先に見つけること**:見張り・電探・光(発砲・探照灯・照明弾)・背後の陸影・航跡。夜の目視の距離は、ガダルカナル沖でほぼ 10,000 yd(9.1km)以内、たいてい 5,000 yd(4.6km)以内。見張りのよい日本海軍で 11km 前後
2. **先に撃つこと、とくに魚雷**:夜戦の大きな損害の多くは、撃ち合いの最初の数分の雷撃から出ている
3. **指揮と統制の遅れ・混乱**:許可を待つ間に射点を失う(タサファロンガ)、旗艦の取り違え(エスペランス)、味方かどうか分からず撃てない・味方を撃つ、司令官の死傷、統制を失った追撃(サマール)
4. **射撃の仕組みの差**:射撃用の電探があるか(スリガオ)、回避運動・煙幕で命中が落ちる(コマンドルスキー)、遠距離の命中率は1〜3%
5. **弾の数と種類**:徹甲弾を撃ち尽くす(コマンドルスキー)、遠距離で撃ちすぎて夜に足りない(スラバヤ)、対地砲撃の弾を揚弾していた(比叡)
6. **応急と一時的な機能の停止**:動力・電路が止まって電探・主砲が使えない(サウスダコタ)、汽缶を焚き直して速力が戻る(ヨークタウン)
7. **航空**:索敵の遅れ・報告の誤り、飛行甲板の兵装・燃料の誘爆、対空砲火・直衛
8. **天候・視界**:スコール・煙幕で目視も射撃も切れる

### 3b. 要るのに、ない・弱いもの(提案。優先の高い順)

| # | 要素 | 史実の根拠 | 今の状態 | 足し方の案 |
|---|---|---|---|---|
| N1 | **キャンペーンの海戦に夜がない** | ソロモンの水上戦は大半が夜 | `navalBattleFile` は 6時開始・晴れ固定・夜の決まりなし | 段階の日付・陣営の意図(輸送・砲撃)から、夜に始まる海戦を作る。陸の夜(5分刻み・1ターンにまとめる)は使わず、1分刻みのまま暗い時間にする |
| N2 | **夜の見つけやすさを「動いているか」でなく速さ(航跡)と背景で** | 三川は航跡を減らすため減速。陸影を背にした艦は見えにくい。島の反射で電探が効かない | 陸の `movingSignatureMultiplier` 1.5 が艦にもかかる(海では全艦が動くので意味がない)。陸地の近くの電探の妨げはない | 艦は速さに応じた見つかりやすさ(例:12ノット以下は小さい)に置き換える。目標の背後や間に陸があると、目視は減り電探は届きにくい(陸の地形のセルで判定) |
| N3 | **主砲の弾数と弾の種類** | コマンドルスキーの撃ち尽くし、スラバヤの撃ちすぎ、比叡の三式弾 | 陸の携行備蓄の弾薬(ゲージ)を流用 | 艦級の `batteries` に1門あたりの徹甲弾・榴弾の数を書き、斉射ごとに減らす。対地砲撃の任務の艦は榴弾から撃つ(艦船への損害が小さい) |
| N4 | **射撃用の電探と、電探の時代差** | スリガオ(Mk8 で 20.8km 初弾命中)と 1942年の SC・SG の差 | 電探は「反応が分かるだけ」で、当たりは一律 0.4 倍 | 編成表に射撃用の電探(`fireControlRadar`)を足し、あれば電探だけの目標でも倍率を上げ、修正の時間も短くする。値は艦級パックの年で分ける |
| N5 | **回避運動と煙幕・スコール** | コマンドルスキー(200発以上が至近)、サマール | ない | 艦の命令に「回避」(撃たれる側の命中が減り、自分の射撃の修正もやり直し)を、駆逐艦に「煙幕を張る」を足す(命令の数を増やさないよう、既存の姿勢の枠を艦用に使う)。スコールは海の局地の視界として天候に |
| N6 | **魚雷を見て避ける** | サマールの大和の反転、タサファロンガ | 魚雷は走るが、艦は避けない | 見えている(昼・照明・近距離)魚雷の扇に向かって艦首か艦尾を向けると当たりにくい、を自動で行う(避けた艦は射撃の修正を失い、戦隊から離れることもある) |
| N7 | **指揮の遅れ・撃つかの判断** | タサファロンガの許可待ち、エスペランスの撃ち方やめ | 魚雷は射程の7割で自動。電探の反応だけの相手にも自動で撃つ | 電探の反応だけの相手には、見分けるまで撃ち始めない(練度で待ち時間)。味方撃ちは作らない(遊びとして不快で、待ち時間で表せる) |
| N8 | **一時的な機能の停止と回復** | サウスダコタの電路、ヨークタウンの汽缶・甲板 | 損傷は浮力の割合で、速力の低下は戻らない(浸水の分だけ戻る) | 抜けた弾に小さな確率で「動力の停止」(速力0・電探と主砲の射撃の指揮が止まる)を足し、応急で数十分〜2時間で戻す。当たり所の表にはしない |
| N9 | **索敵の報告の誤り・遅れ** | 利根4号機の報告(艦種・数の取り違え)、サマールの見誤り | 見つけた相手は正しく分かる(見分けるまでは艦種不明) | 見分けの前の段階で、相手の陣営には艦種を確率で取り違えた報告を出す(霧のフィルタで)。数の誤りは入れない |
| N10 | **夜戦のターンの長さ** | サボ島の砲雷撃戦は30〜40分、第三次ソロモン第1夜も40分ほど | 1時間のターン。条件付き命令は陸のもの | 夜の水上戦のシナリオは 20分のターンにする(`time.turnSeconds`。決まりの変更ではない)。条件付き命令に「敵を見つけたら」のときに「雷撃して反転」を足す案もあるが、命令の数を増やさない決まりとの兼ね合いで要相談 |

### 3c. 要らない(外す・止める)もの:陸から引き継いだ残り

| 要素 | 今の働き | 理由 | 提案 |
|---|---|---|---|
| 動いている目標は見つかりやすい(×1.5) | 艦にもかかる | 海では全艦が動く。差がつくのは速さ(航跡) | N2 で置き換え |
| 制圧のゲージ | 砲戦で ×0.03 だけ減る | 艦には「伏せる・頭を下げる」がない。一時的な停止は N8 で別に表す | 艦は制圧を受けない・制圧で火力を落とさない |
| 先手の士気の倍率 | 見えない敵から撃たれた艦の士気が余計に減る | 艦の士気はもともと命中の倍率にしか効かず、先手の効き目は「先に撃てる」ことで十分に出る | 艦には先手をかけない |
| 姿勢(火力・視界の倍率) | 艦も姿勢を持てる | 艦の姿勢は使っていない。N5 で艦用の動き(回避・煙幕)に使うなら別 | 艦用の姿勢を作るまで、艦の姿勢は既定のまま変えられないようにする |
| 陸の弾薬の携行備蓄 | 艦も弾薬ゲージを持つ | N3 に置き換え | N3 を入れたら艦は使わない |
| 撃ち返し・突破・阻止圏・包囲・陣地・疲労・潰走 | 多くは既に外した | — | 残りがないか S8 で見る |
| 陣形ごとの方位の倍率(旧い戦隊1つ=1ユニット用) | 1隻ずつの艦では使わない | 旧い編成表のためだけに残る | 旧い戦隊の編成表をなくすときに一緒に外す(今は残す) |

### 3d. 入れなくてよいもの(史実にはあるが、このゲームの粒度では重い)

- 当たり所の表・区画ごとの浸水・弾庫の誘爆の細かい判定(方針どおり入れない。轟沈は「抜けた弾の火災・誘爆の確率」の中にまとめてある)
- 海況(波の高さで駆逐艦の射撃や航空の発着艦が落ちる):影響はあるが、確かめに使う海戦で決め手になった例が少ない。天候の「荒天」を足すときにまとめて
- 燃料:1戦(数時間〜2日)の中では決め手にならない。キャンペーンの段階の層で十分
- 対潜戦・潜水艦:太平洋の水上戦・空母戦の確かめには要らない。別の段で
- 味方撃ち:史実にはよくあるが、遊びとして不快。N7 の「見分けるまで撃てない」で表す
- 個々の砲塔・射撃指揮所の破壊の表:砲の損失(S2)と N8 の一時的な停止で足りる

## 3e. 実装の状況(N1〜N10 はすべて入れた)

AI 同士の対戦で分かったこと(S8 の前に見る):キャンペーンの夜戦は片方の艦隊が全滅するまで続きやすい(退く判断が夜は効きにくい)。自動で付く架空の指揮官の特性が、同じ戦場では毎回同じ陣営を有利にする。

## 4. S8 で確かめるときに見る数

- 砲戦:コマンドルスキー(ソルトレイクシティの約830発で、日本側への命中の数)、スリガオ(戦艦の発射数と命中)、第三次ソロモン第2夜(ワシントンの霧島への命中)
- 雷撃:スラバヤ昼(92本で1本)・夜(12本で2隻)、タサファロンガ(米20本で0、日本40本ほどで4本)、サボ島
- 見つける距離:夜の目視 4.6〜9km、日本の見張り 11km 前後
