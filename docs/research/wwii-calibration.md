# 第二次大戦の戦闘とゲームの比較 — 足りない仕組みと調整不足の補正値

目的:ゲームを一度、史実に近づける。WWII(一部 WWI・朝鮮)の戦闘を調べて共通項を出し、ゲームの今の挙動と比べた。

## 調べ方と注意

- **調べ方**:5つのテーマを並行して調べた。テーマは、損耗、テンポ・地形・姿勢、火力支援・航空・空挺、士気・補給・包囲、戦闘15件の事例比較。
- **一次資料は未確認**:作業環境から本文を開けなかった(WebFetch が使えない)。根拠は検索結果に出た二次資料の要約。
- **数値の扱い**:出典ごとに2倍前後ずれる数値が多い。ゲームに入れるときは目安として扱い、確定値は一次資料で裏取りする。
- **一次資料の候補**:Dupuy『Numbers, Predictions and War』『Attrition』、FM 101-10(1944)、ORO-T-117、Cole『The Ardennes』、21 Army Group ORS 報告。
- **ゲームの計測**:AI同士の対戦で測った(バストーニュ30戦、左右対称20戦。1ターン30分、1日は昼15ターン)。

## 1. 史実の共通項(15の戦闘と統計から)

- **P1 損耗は緩やかで、崩れた側だけが急に減る**
  - 師団規模の交戦で、1日の人員損耗は1〜3%(勝った側1〜2%、負けた側2〜3%)。
  - 部隊が小さいほど率は高い。Dupuy の基準値は旅団1.8%/日、大隊約8%/日、中隊約21%/日。
  - 崩壊した側は1日で10〜30%を失う(軍隅里、シディ・ブ・ジッド、第106歩兵師団)。
  - 出典:https://dupuyinstitute.org/2016/06/17/trevor-n-dupuys-combat-attrition-verities/ 、https://dupuyinstitute.org/2017/06/09/attrition-in-future-land-combat/
- **P2 部隊が戦いをやめる理由は、損害より制圧・混乱・奇襲・側面への回り込み**
  - 実際の部隊は、1回の戦闘で10%未満の損害で戦いをやめることが多い(McQuie)。
  - 崩壊時の損害は平均約40%だが、1〜100%にばらつく。Clark は固定の閾値を否定した。
  - 出典:https://dupuyinstitute.org/2018/04/27/what-is-a-breakpoint/ 、https://dupuyinstitute.org/2017/06/23/battle-outcomes-casualty-rates-as-a-measure-of-defeat/
- **P3 死傷の過半は砲兵・迫撃砲**
  - 米軍の欧州・地中海戦域で、砲撃・迫撃砲は死傷の約65%。負傷の約57%が爆発物、小火器は約20%。
  - 制圧は「砲撃の最も重要な効果」(Dupuy)。
  - 出典:https://terrycopp.com/wp-content/uploads/2017/05/counter-mortar-operational-research-in-the-21-army-group.pdf 、https://thekwe.org/topics/casualties/surgeon_general/p_ch3.htm
- **P4 交戦距離は近い**
  - 歩兵の戦闘は大半が300ヤード(約275m)未満(Hitchman、要裏取り)。
  - 戦車戦は、開けた地形で約1,100m、見通しの悪い地形で約370m(AORG)。
  - 出典:https://apps.dtic.mil/sti/pdfs/ADA247186.pdf
- **P5 陣地に入り、対戦車火器を持つ守り手は、攻め手の戦車に一方的な損害を与える**
  - グッドウッド、エルゼンボルン、プロホロフカ、12月25日のシャン/エムルール。
  - 戦車の損失率は人員の損耗率の5〜7倍。損失原因は徹甲弾(戦車+対戦車砲)約69%、砲兵約13%、航空約7%。
  - 出典:https://dupuyinstitute.org/2016/10/25/tank-loss-rates-in-combat-then-and-now/
- **P6 縦隊のまま、または偵察なしで接敵した側は短時間で大損害を受ける**
  - ヴィレル・ボカージュでは15分で30両以上を失った。アラクールのドイツ軍、軍隅里も同じ。
  - 奇襲の補正は×1.1〜2.2で、3日で1日1/3ずつ減る(Dupuy の判断値)。
- **P7 決定的な結末は、正面からの撃破より包囲・退路の遮断・弾薬切れから生まれる**
  - アーネム(弾薬切れで降伏)、アーヘン(包囲されて降伏)、第106歩兵師団(8,000人が捕虜)、チョーシン。
  - 崩壊・包囲された部隊では、損失の8割以上が捕虜・行方不明。
- **P8 包囲は数日〜数週間で決着する**
  - 救出も空中補給もない大きな包囲は、数日〜3週間で大半が投降した(ファレーズ、ルール)。
  - 必要量に見合う空中補給があれば2か月以上もった(デミャンスク)。
  - 死守を命じられた小拠点は、救出がなければほぼ全滅した(テルノポリ)。
- **P9 航空の直接の撃破は小さく、移動を止める効果が大きい**
  - モルタンでは、戦車撃破の主張252両に対し、実際は損失46両のうち航空によるもの9両。
  - 制空権の下で、ドイツ装甲部隊は昼の移動をやめ、非装甲車両を大量に失った。
  - 出典:https://warhistory.org/ja/article/normandy-1944-the-rafs-and-usafs-story
- **P10 退路があれば守り手は遅滞しながら下がり、退路がなければ全滅する**
  - 下がれた例:ザンクト・フィート、エルゼンボルン、オルトーナ。
  - 退路がなかった例:第106歩兵師団、フェイス任務部隊。
- **P11 市街・森林では前進が遅いが、攻め手の損害が特に増えるわけではない**
  - 市街の前進は非市街の1/2〜1/3。損害の交換比はむしろ攻め手に有利(TDI、市街戦304件の比較)。
  - 出典:https://dupuyinstitute.org/2018/06/06/measuring-the-effects-of-combat-in-cities-phase-i/

## 2. ゲームと史実の比較

| 項目 | ゲームの今 | 史実の目安 | 判定 |
|---|---|---|---|
| 交戦中の損耗 | 連隊・大隊が1時間に約5%(1日で約35%) | 大隊で1日約8%、連隊なら数%/日。崩れた側だけ10〜30%/日 | **約5〜10倍、損耗が速すぎる** |
| 攻め手と守り手の損害比 | 0.78〜0.91 | 0.8〜1.6(イタリア)。攻め手の損耗率はやや低いのが普通(Dupuy) | おおむね合う |
| 損害の原因 | 直射のみ60〜67%、砲撃・空襲のみ20〜28% | 砲撃・迫撃砲が約65%、小火器約20〜30% | **砲兵が弱く、直射が強すぎる** |
| 射撃の距離(中央値) | 520〜970m | 歩兵は大半が275m未満、戦車は約370〜1,100m | **歩兵の撃ち合いが遠すぎる** |
| 潰走した時点の損害 | 中央値12〜15% | 戦いをやめるのは10%未満が多く、崩壊時は平均40%(ばらつき大) | おおむね合う(崩れる原因が士気なのは史実どおり) |
| 制圧 | 交戦中の中央値0.02〜0.04。1分に0.02回復するので30分で消える | 制圧が砲撃の主な効果 | **制圧が弱く、すぐ消える** |
| 接触中の前進 | 1ターン約95m(1日約1.4km) | 西欧の平均1.8km/日、突破時4km/日 | 合う |
| 突破の頻度 | バストーニュで1試合約19回 | 師団の交戦で「突破」はまれ(数日に1回程度) | **多すぎる** |
| 陣地の構築 | 30分ごとに1段(陣地3まで1.5時間) | 簡易壕は数分、フォックスホール約2時間、本格的な掘削約5時間、構築陣地は12〜24時間(確度低) | **陣地2〜3が速すぎる** |
| 縦隊から展開 | 30分 | 大隊で1〜2時間(確度低) | やや速い |
| 防御の倍率(突破の判定) | 陣地0〜3で×1/2/3/4.5 | QJM:急造1.3、準備1.5、要塞化1.6、市街×1.4(準備の市街で約2.1)。Dupuy は「1.3〜3倍超」 | 史実より高め(ユーザー判断で硬くした) |
| 砲撃の要請から着弾 | 次のターン(30〜60分後) | 米軍の大隊で約3分、師団で約6分、軍団で約9分 | **遅すぎる** |
| 近接航空支援の到着 | 10分後 | 上空待機機がいれば10〜15分、いなければ数時間 | 待機機がいる場合に限り合う |
| 空襲・近接航空支援の効果 | 砲撃と同じく3つのゲージに損害を与える | 撃破は小さく(主張の約4%)、制圧・士気・移動の阻害が大きい | **撃破に寄りすぎ、移動の阻害がない** |
| 空挺の散らばり | 半径600m | 夜の最良の例で50%が1.6km以内・75%が3km以内、最悪は40km離れる。昼はほぼ正確 | **夜の降下が正確すぎる** |
| 包囲から投降まで | 死守でも3〜8ターン(1.5〜4時間) | 数日〜数週間(空中補給があれば数か月) | **速すぎる** |
| 弾薬の持ち | 撃ち続けると歩兵連隊で3時間、戦車連隊で1時間 | 基本携行量で激戦約3日(確度低)。バストーニュは包囲4日目でほぼ枯渇 | **10〜20倍、減りが速すぎる** |
| 米軍の対戦車火力 | 空挺連隊はバズーカのみ(射程150m) | 対戦車砲(57mm)・駆逐戦車大隊が主役 | **編成データが足りない** |

## 3. 足りない仕組み

1. **奇襲**:最初の接触で見えていなかった側が受ける大きな不利(×1.1〜2.2、数時間〜数日続く)。今は伏撃の初撃の数分だけ。
2. **航空による移動の阻害**:制空権のない側が昼に縦隊で動くと、遅れたり非装甲車両を失ったりする。
3. **観測された目標への即時砲撃**:前線の部隊が見ている目標には、同じターンのうちに数分後に着弾する。事前計画の射撃は今どおり次のターン。
4. **夜の空挺降下の散らばりと集結**:降りてから数ターンかけて戦力がそろう。
5. **崩壊した部隊の損失は捕虜・行方不明が中心**:今は潰走中の損害2.5倍で表している。

## 4. 調整の候補(優先度順)

### 優先度の高いもの

- **A. 損耗を5〜10分の1にする**
  - 直接射撃・砲撃の、戦力ゲージへの効き方を下げる。
  - 制圧と士気への効きは残し、崩れるのは主に制圧・士気で起こす(P1・P2)。
  - 弾薬の消費も合わせて下げる(撃ち続けて数日もつように)。
- **B. 撃ち合いの距離を近づける**
  - 小銃・機関銃の距離ごとの威力を、遠距離で大きく下げる(歩兵は300m以内が主、P4)。
  - 戦車砲・対戦車砲は今のまま。
- **C. 砲兵を死傷の主因にする**
  - 間接射撃の効き(indirectDamageScale)と制圧を上げる。
  - 制圧の回復を遅くし、砲撃の後しばらく残るようにする(P3)。
  - 観測された目標への即時砲撃も入れる(仕組み3)。
- **D. 陣地の構築を遅くする**
  - 段ごとに必要なターン数をデータで持てるようにする。例:陣地1は1ターン、陣地2は4ターン(2時間)、陣地3は10ターン以上(5時間)。
  - 構築陣地(数日)はシナリオ開始時の配置で与える。
- **E. 米軍の対戦車火力を編成データに入れる**
  - 空挺連隊の対戦車砲、駆逐戦車の数など。数値は一次資料で裏取りする(P5)。

### 中くらいのもの

- **F. 包囲から投降までの時間を史実の時間に合わせる**
  - 包囲による士気の低下を小さくし、弾薬・食料が尽きることで崩れるようにする(P8)。
  - 1日のシナリオでは、包囲された部隊はほとんど投降しなくなる。
- **G. 航空の効果を、撃破から制圧・士気・移動の阻害へ移す**(P9、仕組み2)
- **H. 夜の空挺降下の散らばりを大きくし、集結に時間をかける**(仕組み4)

### 低いもの

- **I. 奇襲**(仕組み1)
- **J. 縦隊から展開に2ターン**(確度が低い)

## 5. 史実と合っているもの(変えない)

- 攻め手と守り手の損害比(0.8〜0.9)
- 接触中の前進速度(1日約1.4km)
- 損害が小さいうちに士気で崩れること
- 市街の前進が遅いこと
- 縦隊で遭遇すると不利なこと
