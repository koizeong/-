# 設定値の妥当性の検証(同じ設定値で別の戦いを再現する)

バストーニュで合わせた設定値(ルールパック・汎用の武器と編成表)をそのまま使い、別の3つの戦いを再現した。AI同士の結果を史実と比べ、どこが合わないかを調べる。

- 集計の道具:`packages/ai/test/validation.test.ts`
  - 実行:`VALIDATE=1 GAMES=10 npx vitest run packages/ai/test/validation.test.ts`
  - 勝敗、目標の保持、損耗、機甲の損失、投降を数える
- シナリオ(検証用 v0・概略図。作り直しは `tools/scenarios/build_*.py`)
  - `data/scenarios/krinkelt-rocherath-1944-12-17.json`
  - `data/scenarios/arracourt-1944-09-19.json`
  - `data/scenarios/carentan-1944-06-10.json`

## 資料の状況

一次資料のサイト(history.army.mil、ibiblio.org、wikisource.org、archive.org ほか)は作業環境から開けなかった。以下の史実の値は、検索結果の要約(二次資料)による。

- 損害の数は、資料によって2倍以上違うことがある
- 確かめていない値は、シナリオの作り直しのスクリプトに `TODO(要裏取り)` として出典候補とともに書いた
- 地図は、座標を確かめた村と、つながりを確かめた(または概略の)道路だけで作った
- 森・高地・冠水域の広がりは概略

## 史実の目安(検証の基準)

### クリンケルト=ロッヒェラート

- 米軍は17日夕方から19日夜まで、約2.5〜3日間、双子村を保った。退却は命令によるもので、押し出されたのではない
- 独軍は村より先へ進めなかった
- 独第12SS装甲師団は、最初の3日で戦車136両のうち48〜67両を失った(35〜50%)
  - 第644駆逐戦車大隊だけで17両撃破・3両損傷・突撃砲2両(Cole)
- 米軍の損害も重かった
  - 第9歩兵連隊第1大隊(ラウスデル十字路):約600人のうち残ったのは144〜240人(60〜75%の損害)
  - 第38歩兵連隊:最初の24時間で行方不明389人

### アラクール

- 米軍(A戦闘団)がアラクール一帯を保った。独第113・第111装甲旅団は壊滅した
- 戦車の数は独軍が約2倍だった(独 約180両 対 米 M4 約53両+駆逐戦車)
- 19〜22日の米軍の損失:M4 14両・M5 7両(資料によって違う)
- 独軍の損失:戦車80両以上(全期間で撃破86・損傷114とする資料がある)。交換比はおよそ4〜5対1
- 19日の霧の中の戦いは、75ヤード(約70m)の近さで起きた
- 独軍の装甲旅団の乗員は訓練約2週間で、砲兵を持たず、無線も少なかった

### カランタン

- 第502落下傘歩兵連隊第3大隊は、約1.5〜2kmの堤道を10日午後から11日04時ごろまでかけて越えた
  - 約24時間で戦力の半分〜3分の2を失った
- 独第6降下猟兵連隊は弾薬が尽きかけ、両側面(北東から第327グライダー歩兵連隊、南西を回った第506落下傘歩兵連隊)を脅かされた
  - 11日夜に撤退し、12日に町が落ちた
- 13日の独第17SS装甲擲弾兵師団の反撃は、空挺歩兵を4〜5時間で1〜2km押し戻し、町の460m手前まで迫った
  - 午後に第2機甲師団A戦闘団(戦車約60両)が来て、数時間で押し返した

## 原因(1戦ずつ追って調べた)

### 1. 阻止圏が「近づくこと」そのものを止めている(3つの戦いに共通。いちばん大きい)

- 阻止圏(半径500m)の中で守備隊に近づく動きは、すり抜けでなく肉薄でも、突破判定に勝たないとできない
- 陣地のある町では、阻止の力が4.5倍になる(陣地3)。比のしきい値2.0と掛け合わせると、攻める側に6〜9倍の力が要る
- そのため攻める側は守備隊の500〜700m手前で止まり、小銃の効かない距離で撃ち合うだけになる
  - 小銃の効く距離の区切りは150/300/600m
  - 両軍とも損害が小さく、町は落ちない(カランタン)
  - 攻める側は町を避けて回り込む(クリンケルト)
- 史実では、攻める側は損害を払えば近づけた
  - 近づいた後の近距離戦で、大きな損害が出た(ラウスデル十字路で60〜75%、コールの大隊で半分〜3分の2)
  - その結果として、守備隊が持ちこたえるか、追い出されるかが決まった
- 「突破」は、敵陣を抜けて後ろへ出ることには合っている(`docs/research/breakthrough-history.md`)。肉薄まで止めるのは強すぎる

### 2. 動いている部隊と止まっている部隊で、見つかりやすさが同じ(アラクール)

- 探知の距離は、見る側の視界と、見られる側の地形・姿勢だけで決まる
- 動いているかどうかは効かない
- 史実の霧の中の戦いでは、止まって待ち構える側が、近づいてくる縦列を先に見つけて先に撃った
- 今は、数で勝る側(独軍は戦車が約2倍)がそのまま押し切る

### 3. 部隊の練度がない(アラクール、ほか全般)

- 同じ編成表なら、どの部隊も同じ強さになる
- 史実で数の少ない米軍が勝った理由のひとつは、独軍の装甲旅団の練度の低さ(訓練約2週間、無線が少ない、砲兵なし)だった
- 国民擲弾兵と空挺部隊の違いも、今は編成表の中身の違いでしか表せない

### 4. AIの不具合(直した)

1. **砲撃を待ち続けて突入できない**
   - 総攻撃は準備砲撃を待ってから突入する。砲兵が陣地を変えている間は撃てないのに、撃てる砲兵がいるとみなして待ち続けていた
   - 対処:展開済みの砲兵だけを数え、いなければ待たずに突入する
2. **砲兵が陣地を変えてばかりいた**
   - 霧で敵が見えなくなるたびに「撃てる目標がない」として陣地を変えていた
   - 対処:敵が押さえている目標が射程内なら動かない

この2つは直したが、3つの戦いの結果はほとんど変わらなかった。原因の中心は1〜3にある。

直した後のバストーニュ8日間版(20戦)は、次のとおり。

- 米軍の決定的勝利 16
- 米軍の限定的勝利 1
- 独軍の限定的勝利 2
- 独軍の決定的勝利 1

### 5. シナリオ側の欠け(v0の概略図による)

- **クリンケルト**:ヴィルツフェルトの南東にいた米軍の阻止部隊(ギンダーの部隊)を入れていない。森の広がりも概略
- **カランタン**:冠水域の広がりと4つの橋の位置が未確認。北東・南西の乾いた土地からの回り込みが、史実ほどしやすくない可能性がある
- **アラクール**:265・318・257高地と運河が入っていない。史実では、高地の稜線の陰から撃つ戦車が大きな戦果を上げた

## 損害の水準と攻め方の違い(遮二無二の突撃と持続できる攻勢)

### 何が問題だったか

- 大隊が同じ規模の大隊(陣地2)を攻め続ける実験をした。攻め手は戦力を**3〜4%失っただけで潰走**し、姿勢を変えても同じだった
- 原因:損害は戦力(重み0.05)より士気(重み1.5)に30倍早く効き、戦力がほとんど減らないうちに崩れていた
- 史実の目安(出典は下)
  - 師団規模の交戦の損失:1日あたり1〜3%(Dupuy)
  - 大隊の攻撃:1日あたり6〜12%。陣地への初日の攻撃は10〜19%
  - オマハ海岸の第一波:1日で約37%
- 出典
  - Dupuy Institute『Average Losses per Day in Division-level Engagements』 https://www.dupuyinstitute.org/2023/04/25/average-losses-per-day-in-division-level-engagements-on-the-eastern-front-in-1943
  - Dunnigan の表(フォーラムの引用・未確認) https://community.battlefront.com/topic/89255-james-dunnigan-on-casualties-in-1982/

### 入れたもの

| 項目 | 内容 |
|---|---|
| 1. 損害の戦力への振り分け | 0.05 → **0.12**。標準の姿勢で陣地を攻める大隊は、崩れるまでに約7%を失う。0.17(約10%)ではクリンケルトは史実に合ったが、バストーニュ8日間の累計が両軍5割を超えたので間を取った |
| 2. 強襲(遮二無二の突撃) | 撃たれたときの士気の減り方 0.4倍(崩れずに損害を払う)。息切れした後は士気の回復が半分 |
| 3. AIの使い分け | 強襲は、残りのターンが少ない・守備隊が弱っているときだけ。それ以外は標準の姿勢で攻める(持続できる攻勢):取りついたら標準の姿勢のまま詰め、動揺したら下がる |
| 4. 蹂躙 | 持ち場を守っている部隊が、敵に取りつかれたまま(250m以内)崩れると、戦力を15%失う(逃げ遅れ・捕虜) |
| AIの直し(測り直しで見つかったもの) | 1. 守備隊は目標の範囲の中ならその場で陣地を築く(前は中心へ向かい続け、町に入り込んだ敵の前で陣地のないまま全滅していた)<br>2. 消耗した部隊は攻撃から下がる<br>3. 撃たれている部隊は展開したまま動く(縦隊で動くと、接敵で止まって展開し直すのを繰り返していた) |

## 東西の差を調べた(対称シナリオ・決戦)

- 疑い:対称 26:13、決戦 独13:米4 と、東軍(de)が2倍前後勝っていた
- 位置か名前か:陣営の名前を入れ替えた同じ盤面(西が de、東が us)でも de が勝った(対称 29:10)。東という位置のせいではない
- 処理順:ステップごとの部隊の処理順を陣営で逆にしても、結果は1戦も変わらなかった(移動の処理順は効いていない)
- 乱数の当たり外れ:名前ごとに違うのは、AIの判断のぶれに使う乱数の系列(シード・ターン・陣営名から作る)。名前を入れ替えると盤面が鏡写しになり、ほぼ同じ試合が再現されるので、同じ当たり外れが2回出ていた
- 別のシードで確かめた(各40戦):対称は 17:21・25:15・19:18、決戦は 8:9・10:10・8:8。160戦の合計は対称 de 87:us 67(56%。偏りなしとの差は標準偏差の約1.6倍で、誤差の範囲)、決戦 de 35:us 34
- 結論:東西で扱いの違う処理は見つからなかった。40戦では、乱数の当たり外れで 2:1 程度の偏りが出うる。偏りを判断するときは160戦以上で見る
- ついでに分かったこと:同じシードでも、命令・司令部コマンドを渡す順番(陣営の順)が違うと結果が変わる(斥候などの乱数を引く順番が変わるため)。同じ入力なら同じ結果になるので、決定論は保たれている

## 残っている課題

1. **守る側の損害が小さい**:連隊を大隊に分けて、クリンケルトの米軍は3%から10%になった。カランタンの米軍(攻める側)とバストーニュ19日の両軍は、まだ小さい
5. **アラクールの米軍AIが反撃に出ない**:村を独軍に渡したままになる
6. **遮二無二の突撃をいつ使うか**:急ぎ度で決めるようにした(上の節)
8. **カランタンの独軍の消耗**:
   - 何が起きていたか:独第6降下猟兵連隊は弾薬0.3で始まるが、南西の集積所(60t)から数ターンで満タンに補給されていた。「弾薬がひどく不足」が効いていなかった
   - 史実:備蓄の多くを車両ごと失い、届いたのは11〜12日夜の空中補給だけ(十分だったかは資料で食い違う)
     - 出典:EUCMH『6.Fallschirmjäger-Regiment - Normandy』 https://eucmh.com/2025/01/22/6-fallschirmjager-regiment-normandy-oberst-friedrich-von-der-heydte/4/
     - 出典:Warfare History Network『The Lions of Carentan Part II』 https://warfarehistorynetwork.com/article/the-lions-of-carentan-part-ii-defending-carentan/
   - 対処:独軍の集積所をその空中補給の分(8t、量は TODO(要裏取り))だけにした
   - 結果(10戦):町が落ちるのは4戦 → 7戦。落ちるのは平均75ターン目(3日目の朝。史実は12日の朝で69ターン目)
   - 残り:米軍の損耗は2%のまま。史実では第502落下傘歩兵連隊第3大隊が2日で約700人から132人に減った。考えられる原因は2つ
     - 独軍の兵力が史実より小さい:第6降下猟兵連隊は6月6日に約4,500人で、第2・第3大隊と連隊の重火器中隊が残っていた。ゲームは汎用の国民擲弾兵大隊2つ
     - 冠水域の広がりが概略:米軍が冠水域を広く散って進めるので、堤道に詰まって撃たれる形にならない
7. **バストーニュ8日間は米軍に寄った**:守備隊がその場で陣地を築くようになり、独軍の損耗が5〜6割に達する。急ぎ度を入れても変わらず、史実の結末(米の限定的勝利)はほとんど出ない
2. **アラクールの交換比**:勝敗は合ったが、戦車の損失は独軍有利のまま。高地の陰からの射撃(稜線射撃)と、独軍が少しずつ投入したこと(シナリオでは一斉に動く)が入っていない
3. **カランタンの冠水域と回り込み**:冠水域の広がりが概略で、北東・南西からの回り込みが史実ほどしやすくない可能性がある
4. **クリンケルトの後方**:ヴィルツフェルトの南東にいた米軍の阻止部隊が入っていない
