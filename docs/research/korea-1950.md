# 朝鮮戦争・釜山円陣から仁川へ 1950年8月4日〜9月28日 キャンペーン v0 の根拠

作り直しは `tools/campaigns/build_korea_1950.py`(出力 `data/campaigns/korea-1950.json`)。
この作業環境からは資料の本文を開けず、検索結果の要約で確かめた範囲で置いた。

## 単位と期間・編成
- 1段階=4日、14段階(8月4日〜9月28日)。部隊1つ≒1個師団(連隊の編成表で代える)
- 生成器の編成「1950年の朝鮮」(`data/generators/missions.json` の `1950-korea`):国連軍は米の1950年の歩兵連隊・M4A3E8 の戦車大隊、朝鮮人民軍は歩兵連隊・T-34-85 の戦車連隊(国ごとの実数のパック)
- 地形の傾向は西欧の農村で代えた(TODO:朝鮮の山地の傾向)

## 航空隊
- 極東空軍は8月に1日平均239の航空支援の出撃、出撃の6割より多くが戦場の敵の部隊へ([Air & Space Forces Magazine『Air War Korea, 1950-53』](https://www.airandspaceforces.com/article/1000korea/))。第5空軍が近接支援、第77任務部隊の空母機も支えた
- 置き方:編隊1つ=実機約40機。239 ÷ 3 ≈ 80機の戦闘爆撃機を2編隊、戦闘機0.5編隊(仮置き)。空母機と朝鮮人民軍の航空は入れていない(TODO)
