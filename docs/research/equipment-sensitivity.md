# 編成の差はどれだけ戦局に効くか(測定 v0)

将来のキャンペーン(戦闘の前に自分で装備・編成を決める)に向けて、今のエンジンで編成の差がどれだけ勝敗と損害に出るかを測った。
道具:`SENSITIVITY=1 GAMES=40 npx vitest run packages/ai/test/sensitivity.test.ts`

| 対戦車寄り | 0.4%/2.0% | 1.0%/4.8% | 1.1%/1.9% | 2.5%/3.0% | **0.7%**/3.1% |

- 編成の差は、撃ち合いの比には素直に出る(対歩兵寄りは歩兵相手に 2.4%/1.1%、対戦車寄りは 0.4%/2.0%)。火力を上げると、こちらの受ける損害も少し減る(撃って相手を制圧するため)
- ただし**絶対量が小さい**:正面から4時間撃ち合っても、連隊が失うのは 1〜5%。比が2倍違っても、戦局を変える前に包囲・側面・目標の取り合いで決着がつく
- **相性は「ほぼ戦車だけの相手」にしか出ない**:機甲戦闘団(戦車と機甲歩兵の混成、装甲化率0.6)には、機関銃でも効果の4割が通る。対戦車寄りより対歩兵寄りの方がよく効いた。純粋な戦車連隊(0.9)では対戦車寄りが基準の2倍余り効くが、0.7% と小さい
- 戦車連隊に対しては、どの歩兵の編成も一方的にやられる(受 3%前後)

## 原因と、編成を効かせるための方向(全体が固まってから)

1. **正面の撃ち合いの殺傷力が低い**:差が勝敗まで届かない。史実の損耗との比較(`docs/research/wwii-calibration.md`)と合わせて、正面の撃ち合いでどれだけ削れるべきかを決め直す。今は側面・包囲・士気の方が桁違いに強い
2. **装甲化率の按分で相性がぼける**:混成の部隊は、非装甲向けの武器でもかなり削れる。相性を出すなら、装甲の部分と非装甲の部分を分けて撃つ(要素ごとに装甲を持つ)などが考えられる
3. **値段がない**:ポイントで装備の値段を決め、同じ値段の中での選択にする(量か質か、対戦車か対歩兵か)
4. **AI が相性を使わない**:対戦車の部隊を敵の機甲に当てる判断がない。プレイヤーの選択が効くには、敵の AI も相手を見て当てる必要がある
5. **キャンペーンの持ち越し**:1戦では小さい差(耐久・弾薬の持ち・燃費)も、損害と備蓄が次の戦闘に残れば積み上がる

## 対策を入れてみた(2回目)

入れたもの(ユーザー判断:上の1・2と、損耗による士気の上限):

1. **正面の撃ち合いの決着を早める**:直接射撃の士気への効きの倍率(`combat.directFireMoraleMultiplier`)を入れた。損害(戦力)は史実どおり小さいまま、撃ち負けた側が先に動揺するようにする狙い(史実:部隊が戦いをやめる理由は損害より制圧・混乱。`wwii-calibration.md` の P1・P2)。ルールパックの以前の目安「歩兵連隊どうし400mで3時間で動揺」に対し、1倍では4時間撃ち合っても士気0.8までしか下がらなかった
2. **混成の部隊を、装甲の部分と非装甲の部分に分ける**:編成表の要素に `armored` の印を付ける(戦車中隊・戦車駆逐中隊)。撃たれると、武器の効果と今の割合に応じてそれぞれの部分が減り、減った部分の武器は撃てなくなる。機関銃は随伴歩兵だけを削り、歩兵がいなくなった戦車には対戦車の武器しか効かない
3. **損耗による士気の上限**:士気は 1 − 係数 × 失った戦力 までしか回復しない(`morale.lossCeilingFactor`)

### どれが何を動かしたか(アラクール40戦。史実は米軍の勝ち)

| 設定 | 勝敗 | 独の機甲の損失 |
|---|---|---|
| 3つともなし | 米17・独16・分7 | 41% |
| 分割だけ | 米20・独15・分5 | 34% |
| 上限1.0だけ | 独22・米14・分4 | 31% |
| 士気2倍だけ | **独36・米3**・分1 | 13% |
| 分割+士気1.5倍+上限0.5 | **独34・米6** | 17% |
| 分割+上限0.5(採用) | 独19・米15・分6 | 34% |

- **直接射撃の士気の倍率は、1.5倍でも史実から大きく外れた**。撃ち合いが士気で早く決着するほど、大きな部隊(独の装甲旅団)が一方的に勝つ。史実で米軍が勝てた理由(霧・陣取り・練度・駆逐戦車の使い方)が、エンジンではまだ弱いので、それを打ち消せない。**倍率は仕組みだけ入れて1倍のまま**にした
- 分割は勝敗をほとんど動かさない。上限は1.0で独側へ寄ったので0.5にした

### 編成の効き目は変わらなかった

対称シナリオの対戦・一騎打ちとも、1回目の測定とほぼ同じ数字になった(一騎打ちの差は0.1%程度)。

- 分割の効果は、混成の部隊の随伴歩兵が削られきってから出る。4時間の一騎打ちでは、随伴歩兵は数%しか減らないので、まだ効かない
- 士気の上限は、損耗が積み重なる長い戦い・キャンペーンで効く仕組みで、14ターンの対称シナリオ(損耗4%前後)では効かない
- 正面の撃ち合いで決着がつかない、という一番の原因は残っている。士気で決着を早めると史実から外れるので、先に「史実で小さい側・守る側が勝てた理由」(陣取り・霧・練度・駆逐戦車の待ち伏せ)をエンジンに入れ、その後で決着の速さを上げる順番がよい
