# シナリオパック(MOD)の作り方

シナリオパックは、シナリオ・キャンペーン・手引き・武器と編成表を1つのフォルダにまとめたものです。
ゲームのコードには手を入れず、JSON のファイルを置くだけで新しい戦いを足せます。

見本:`docs/modding/sample-pack/`(架空の小さな渡河の戦いと、汎用の編成表を少し変えた大隊が1つ入っています)。

## 置き場所

| 起動のしかた | 読み込むフォルダ |
| --- | --- |
| `pnpm dev`・`pnpm start` | リポジトリの `mods/` と、環境変数 `MODS_DIR`(複数なら Windows は `;`、ほかは `:` で区切る) |
| デスクトップ版 | 同梱の `mods/` と、ユーザーのフォルダ(Windows では `%APPDATA%` の下のアプリのフォルダの `mods`。表紙の「シナリオパック」→「パックのフォルダを開く」で開けます) |

`pack.json` を持つ下のフォルダを、1つずつパックとして読みます。置いた後は起動し直してください(デスクトップ版は「起動し直す」ボタン)。

## フォルダの中身

```
my-pack/
  pack.json           名札(必須)
  scenarios/*.json    シナリオ
  campaigns/*.json    キャンペーン(作戦地図)
  tutorials/*.json    手引き
  weapons/*.json      武器パック
  toe/*.json          編成表のパック
  rulepacks/*.json    ルールパック(時代ルール)
  branches/*.json     兵科パック
```

ない下のフォルダは飛ばします。ファイルの形は、`data/` の下の同じ名前のフォルダのファイルと同じです(スキーマは `packages/sim-core/src/scenarioFile.ts`・`rulepack.ts`・`toe.ts`・`weapon.ts`、キャンペーンは `packages/campaign/src/schema.ts`、手引きは `packages/protocol` の `TutorialSchema`)。

### pack.json

```json
{
  "id": "my-pack",
  "name": "画面に出す名前",
  "version": "1.0.0",
  "author": "作った人(省略できる)",
  "description": "パックの説明(省略できる)",
  "requires": ["ほかのパックの id"]
}
```

- `id` は英小文字・数字・ハイフンにして、ほかのパックと重ならないようにします。
- `requires`:ほかのパックの武器・編成表を使うときに、そのパックの id を書きます。そのパックを先に読みます。

## 決まりごと

- **誤りが1つでもあるパックは、丸ごと読み込みません**(半端な状態で遊べてしまわないように)。誤りは、表紙の「シナリオパック」の画面と、サーバーの起動時の表示に、ファイルの場所つきで出ます。
- シナリオ・武器・編成表の ID は、基本のデータやほかのパックと重ねられません。パックの id を頭に付けると重なりにくくなります(例:`mypack-kursk-1943`)。
- 基本のデータ(`data/`)の武器・編成表・ルールパックはそのまま使えます。シナリオの `packs` に id を書いてください(配列なら後ろのものが前のものに重なります)。
- キャンペーン・手引きに誤りがあれば、そこだけ外して知らせます(シナリオは読みます)。
- 史実のシナリオでは、分からない値を推測で埋めずに `TODO(要裏取り)` と書いて、出典の候補を添えてください(`notes` や `description`)。

## 確かめる

```
pnpm pack:check <パックのフォルダ>            読み込みと、両陣営の AI が1ターン目に弾かれる命令を出さないか
pnpm pack:check <パックのフォルダ> --ai 10    さらに、シナリオごとに AI 同士で10戦して、勝率と失った戦力の割合を出す
```

mods のフォルダを渡すと、中のパックを全部確かめます。誤りがあれば終了コード 1 で終わります。
AI 同士の勝率が75%を超えると「偏り」と出ます(10戦以上のとき)。目安なので、史実で一方的だった戦いならそれで構いません。

## Python のスクリプトで作る

`tools/scenarios/` の build スクリプトの道具(概略図 `Sketch`・部隊 `unit`・目標 `objective`・上級部隊 `formations` など。`common.py`)は、パックのシナリオを作るときにも使えます。
書き出し先は `common.output_path(ROOT, "data/scenarios/xxx.json", "xxx.json")` で決め、引数 `--out <フォルダ>` か環境変数 `SCENARIO_OUT_DIR` を付けるとそのフォルダに書きます。

```
python3 mods/my-pack/tools/build_xxx.py --out mods/my-pack/scenarios
```

## 配る

パックのフォルダを zip にして渡し、受け取った人はそれを展開して mods のフォルダに置くだけです。
オンライン対戦では、両方の PC に同じパック(同じ版)を入れてください。
